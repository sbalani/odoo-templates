# Odoo report templates (Odoo 18)

## AFRS Self-Billing Report

A small QWeb inheritance addon depending only on `account`. It extends
`account.report_invoice_document`; it does not modify Odoo core or accounting data.

For vendor bills (`in_invoice`) in the purchase journal named exactly
**Autofacturas - Revenue Share**, it:

- Displays **FACTURA** as the title.
- Keeps the existing invoice number (`o.name`), including the AFRS sequence.
- Displays **Facturación por el destinatario** above the invoice information.

Other vendor bills, customer invoices and credit notes retain their existing
headings. Invoice lines, VAT, taxable base and total sections are untouched.
The two required Spanish phrases stay in Spanish regardless of report language.
The regular Vendor Bill label and its existing translations remain untouched.
Matching uses the journal name, not the invoice prefix, and applies in each company
with that exact purchase-journal name. Renaming the journal stops the customization.
Draft bills also get the requested wording; no number is generated by this addon.

## Cloudpepper installation

1. Add `https://github.com/sbalani/odoo-templates.git` as a custom addons repository,
   selecting branch **18.0**. The addon folder is at the repository root.
2. Pull/rebuild the Odoo instance through Cloudpepper.
3. In Odoo developer mode, update the Apps list, remove the Apps-only filter, and
   install **AFRS Self-Billing Report** (technical name `afrs_self_billing_report`).
4. Print a bill from **Autofacturas - Revenue Share**. Confirm the title, existing
   AFRS number, notice, and unchanged VAT/base/total layout. Print a normal vendor
   bill and customer invoice to confirm their original headings.

Future changes require a Cloudpepper pull and an Apps upgrade of this addon.
Uninstalling removes the inherited view and restores the original report.
Previously stored PDF attachments are not rewritten; validate with a freshly
rendered report. A separate Studio/custom report that does not inherit the standard
invoice document would need its own adaptation.

## Validation

GitHub Actions installs the addon on Odoo 18 with PostgreSQL and runs report
rendering tests for journal isolation, invoice numbering and unchanged totals.
The live Cloudpepper database and its additional report customizations are not
accessible from this repository.

```sh
odoo -d afrs_test -i afrs_self_billing_report --without-demo=all \
  --test-enable --test-tags /afrs_self_billing_report --stop-after-init
```
